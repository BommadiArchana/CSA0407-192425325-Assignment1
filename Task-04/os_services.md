# TASK 04 – Operating-System Services

## 1. Introduction

An operating system provides essential services to manage hardware, execute programs, handle files, allocate resources and protect system data. Different hospital environments require different OS services.

## 2. Operating-System Services for Each Environment

| OS Service | Patient Monitors | Nurses' Tablets | Doctors' Workstations | Database Server | MRI Server |
|---|---|---|---|---|---|
| User Interface | Simple display | Touch interface | Graphical interface | Admin interface | Graphical interface |
| Program Execution | Essential | Essential | Essential | Essential | Essential |
| I/O Operations | Sensor input | Touch and network | Keyboard and mouse | Disk and network | Scanner input |
| File System | Basic logging | Local storage | Full file system | Reliable database storage | Large image storage |
| Communication | Alert transmission | Wireless network | Network access | Hospital network | High-speed data transfer |
| Error Detection | Essential | Essential | Essential | Essential | Essential |
| Resource Allocation | Priority scheduling | Battery-aware | Multitasking | CPU and memory management | Processor allocation |
| Accounting | Basic | Usage tracking | Usage tracking | Detailed logging | Processing records |
| Protection and Security | Essential | Essential | Essential | Strict access control | Secure access |

## 3. Services That Can Be Removed from Bedside Monitors

To make bedside monitors smaller and faster, unnecessary services can be removed:

- Unnecessary graphical applications.
- Background entertainment services.
- Unused printing services.
- Unnecessary user accounts and applications.
- Nonessential background processes.

Essential monitoring, alarm handling, communication and security services must remain active.

## 4. Essential Services for the Database Server

The central database server requires:

- Reliable file and database management.
- Process and memory management.
- Resource allocation.
- Network communication.
- Error detection and recovery.
- User authentication and access control.
- Accounting and audit logging.
- Backup and recovery services.

These services ensure continuous access and protection of patient records.

## 5. Protection of Patient Records

The operating system protects patient information through:

- User authentication using passwords and secure login.
- File permissions and role-based access control.
- Process isolation to prevent unauthorized access.
- Encryption and secure communication.
- Audit logs to track data access and modifications.
