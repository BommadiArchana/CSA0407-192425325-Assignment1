# 🏥 Smart Hospital – Operating System Design

### Operating Systems | Assignment 1

---

## 📌 Project Overview

A Smart Hospital uses different computing environments to manage patient monitoring, medical records, medical imaging and communication between healthcare professionals.

Each environment has different requirements in terms of processing speed, reliability, security, memory management and resource utilization.

This assignment focuses on evaluating these requirements and designing a suitable Operating System (OS) plan for a Smart Hospital.

Through this assignment, various Operating System concepts are explored, including OS structures, system calls, process management, CPU protection, memory hierarchy, I/O systems and performance analysis.

The final objective is to develop a reliable, secure and scalable operating-system design that supports modern healthcare environments.

## 🎯 Assignment Objectives

- Analyze the requirements of different hospital computing environments.
- Identify suitable types and structures of operating systems.
- Understand essential operating-system services.
- Examine system calls and their execution mechanisms.
- Analyze system-call overhead and performance.
- Study process creation, execution and termination.
- Understand CPU protection and memory management.
- Evaluate memory hierarchy and I/O techniques.
- Compare operating-system performance using practical measurements.
- Develop an operating-system recommendation for a Smart Hospital.
- Adapt the design to support remote patient monitoring and cloud-based healthcare.

## 🔍 Practical Analysis

The practical components of this assignment focus on understanding how operating systems manage resources and execute operations.

The analysis includes:

- Comparing system-call frequency for different buffer sizes.
- Understanding the transition between user mode and kernel mode.
- Examining process creation and execution.
- Comparing process and thread creation overhead.
- Studying memory organization and data-transfer techniques.
- Evaluating performance through execution-time measurements.

## 🏥 Final Smart Hospital Design

The proposed Smart Hospital design considers different operating-system requirements for each environment.

- **Patient Monitoring:** Real-time processing and reliable alarm handling.
- **Nurses' Tablets:** Mobility, battery efficiency and secure access.
- **Doctors' Workstations:** Multitasking and efficient application execution.
- **Database Server:** Reliable storage, availability and data protection.
- **MRI Imaging Server:** High processing capability and efficient data transfer.
- **Partner Hospital Connectivity:** Secure communication and distributed data access.

The final design also considers remote patient monitoring, cloud-based medical records, data security and scalability.
